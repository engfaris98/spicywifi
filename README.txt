SpicyWiFi Agent - GitHub Pages
==============================

1) افتح ملف index.html بأي محرر نصوص.
2) ابحث عن الأرقام التجريبية التالية واستبدلها بأرقام حساباتك:
   07XX XXX XXXX
   XXXX XXXX XXXX XXXX
3) استبدل روابط Telegram وWhatsApp والبريد الإلكتروني.
4) استبدل رابط زر تحميل APK بالرابط الحقيقي.
5) ارفع ملف index.html إلى مستودع GitHub.
6) من Settings > Pages اختر Deploy from a branch ثم main / root.

الصفحة متجاوبة وتعمل على الهاتف والكمبيوتر ولا تحتاج إلى ملفات إضافية.
